# STM32

> STM32 微控制器系列

STM32 是意法半导体（STMicroelectronics）推出的 32 位微控制器系列，基于 ARM Cortex-M 内核，广泛应用于嵌入式系统开发。STM32 系列包含 F0/F1/F2/F3/F4/F7/H7/L0/L1/L4/L5/G0/G4/U5 等多个子系列，覆盖从超低功耗到高性能的各种应用场景。

## 核心特性

- 基于 ARM Cortex-M0/M0+/M3/M4/M7/M33 内核
- 丰富的外设：GPIO、UART、SPI、I2C、ADC、DAC、定时器、DMA
- 多种低功耗模式：睡眠、停机、待机
- 完整的开发工具链：STM32CubeMX、STM32CubeIDE、HAL 库
- 广泛的生态系统和社区支持

## 开发流程

1. 使用 [[STM32CubeMX]] 进行引脚和时钟配置
2. 生成初始化代码（HAL/LL 库）
3. 在 [[STM32CubeIDE]] 或 Keil MDK 中编写应用代码
4. 使用 [[调试]] 工具进行调试和测试

## 相关概念

- [[ARM Cortex-M]] - 底层内核架构
- [[GPIO]] - 通用输入输出
- [[UART]] - 串行通信接口
- [[中断]] - 中断系统
- [[电源管理]] - 低功耗设计

# ARM Cortex-M

> ARM Cortex-M 处理器内核

ARM Cortex-M 是 ARM 公司专为嵌入式系统设计的处理器内核系列，是 STM32 微控制器的核心架构。Cortex-M 系列采用 RISC 架构，具有低功耗、高性能、实时响应等特点。

## 内核系列

| 内核 | 架构 | 特点 |
|------|------|------|
| Cortex-M0 | ARMv6-M | 超低功耗，最小面积 |
| Cortex-M0+ | ARMv6-M | M0 增强版，更低功耗 |
| Cortex-M3 | ARMv7-M | 高性能，主流应用 |
| Cortex-M4 | ARMv7E-M | 带 DSP 和 FPU |
| Cortex-M7 | ARMv7E-M | 超高性能，双发射 |
| Cortex-M33 | ARMv8-M | 安全扩展，TrustZone |

## 关键特性

- **NVIC**：嵌套向量中断控制器，支持中断优先级和嵌套
- **SysTick**：系统定时器，用于 RTOS 时钟节拍
- **MPU**：内存保护单元，增强系统安全性
- **FPU**：浮点运算单元（M4F/M7）

- [[中断]] - NVIC 中断管理

# GPIO

> 通用输入输出端口

GPIO（General Purpose Input/Output）是 STM32 最基本的外设，用于与外部设备进行数字信号交互。STM32 的 GPIO 端口分为多组（GPIOA-GPIOH 等），每组 16 个引脚。

## 工作模式

| 模式 | 说明 |
|------|------|
| 输入浮空 | 引脚电平不确定 |
| 输入上拉 | 默认高电平 |
| 输入下拉 | 默认低电平 |
| 模拟输入 | 用于 [[ADC]] 采集 |
| 开漏输出 | 只能拉低，需外接上拉 |
| 推挽输出 | 可主动输出高低电平 |
| 复用推挽 | 外设功能输出 |
| 复用开漏 | 外设开漏输出 |

## 配置要点

- 通过 GPIOx_MODER 寄存器设置模式
- 通过 GPIOx_OTYPER 选择推挽/开漏
- 通过 GPIOx_PUPD 设置上拉/下拉
- 通过 GPIOx_OSPEEDR 设置输出速度
- 通过 GPIOx_AFR 选择复用功能

# UART

> 通用异步收发传输器

UART（Universal Asynchronous Receiver/Transmitter）是最常用的串行通信接口之一，STM32 的 UART 外设支持多种通信模式。

## 主要特性

- 可配置波特率（最高 4.5 Mbps for STM32F4）
- 支持 8/9 位数据位
- 支持 1/2 位停止位
- 支持奇偶校验
- 支持硬件流控（CTS/RTS）
- 支持 DMA 传输
- 支持 LIN、IrDA、SmartCard 模式

## 编程模型

```c
// HAL 库发送
HAL_UART_Transmit(&huart1, data, len, timeout);
// HAL 库接收
HAL_UART_Receive(&huart1, buf, len, timeout);
// 中断接收
HAL_UART_Receive_IT(&huart1, buf, len);
// DMA 接收
HAL_UART_Receive_DMA(&huart1, buf, len);
```

## 常见问题

- 波特率不匹配导致乱码
- 未正确处理接收中断导致数据丢失
- 硬件流控信号接错

# ADC

> 模数转换器

ADC（Analog-to-Digital Converter）将模拟信号转换为数字值，是 STM32 重要的模拟外设。

## 主要特性

- 12 位分辨率（部分系列 16 位）
- 多通道扫描模式
- 支持单次/连续转换
- 支持 DMA 传输
- 内置温度传感器和 VREFINT
- 支持模拟看门狗
- 采样时间可配置

## 转换模式

| 模式 | 说明 |
|------|------|
| 单次转换 | 转换一次后停止 |
| 连续转换 | 持续转换不停止 |
| 扫描模式 | 自动扫描多通道 |
| 间断模式 | 分组扫描 |

## 与 DMA 配合

ADC 与 [[DMA]] 配合可实现高效数据采集：
1. 配置 ADC 为连续转换 + 扫描模式
2. 启用 DMA 传输，目标地址为内存缓冲区
3. DMA 自动搬运转换结果，CPU 无需干预

# 定时器

> STM32 定时器外设

STM32 定时器是功能最丰富的外设之一，可用于计时、PWM 生成、输入捕获、输出比较等。

## 定时器分类

| 类型 | 位数 | 说明 |
|------|------|------|
| 高级定时器 | 16 | TIM1/TIM8，带互补输出和死区 |
| 通用定时器 | 16/32 | TIM2-TIM5，常用定时/PWM |
| 基本定时器 | 16 | TIM6/TIM7，仅定时和 DAC 触发 |

## 主要功能

- **基本定时**：周期性中断
- **输出比较**：生成 PWM 波形
- **输入捕获**：测量脉冲宽度/频率
- **编码器接口**：读取电机编码器
- **主从模式**：定时器级联

```c
// 配置 PWM 输出
TIM_OC_InitTypeDef sConfigOC = {0};
sConfigOC.OCMode = TIM_OCMODE_PWM1;
sConfigOC.Pulse = 500;    // 占空比
sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;
HAL_TIM_PWM_ConfigChannel(&htim3, &sConfigOC, TIM_CHANNEL_1);
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
```

# 中断

> STM32 中断系统

STM32 的中断系统基于 ARM Cortex-M 的 NVIC（嵌套向量中断控制器），支持灵活的中断优先级管理和快速中断响应。

## 中断类型

- **内核异常**：Reset、NMI、HardFault、SVCall、PendSV、SysTick
- **外部中断**：EXTI（GPIO 外部中断）
- **外设中断**：UART、SPI、TIM、ADC 等外设中断

## 优先级管理

- 每个中断有抢占优先级和子优先级
- 抢占优先级高的可以打断低的
- 同抢占优先级按子优先级排序
- 优先级分组通过 NVIC_PriorityGroupConfig 设置

## EXTI 外部中断

```c
// 配置按键外部中断
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
    if (GPIO_Pin == KEY_PIN) {
        // 处理按键事件
    }
}
```

# DMA

> 直接内存访问

DMA（Direct Memory Access）允许外设直接与内存进行数据传输，无需 CPU 干预，大幅提升系统效率。

## DMA 特性

- 支持内存到内存、外设到内存、内存到外设传输
- 支持循环模式（Circular）和正常模式（Normal）
- 支持双缓冲模式
- 可配置数据宽度和对齐方式
- 每个通道有独立的中断标志

## 常用场景

| 外设 | 方向 | 说明 |
|------|------|------|
| [[ADC]] | 外设→内存 | 批量采集模拟数据 |
| [[UART]] | 双向 | 高速串口收发 |
| [[SPI]] | 双向 | 快速 SPI 通信 |
| 内存→内存 | 内存→内存 | 大块数据拷贝 |

## 编程示例

```c
// ADC + DMA 连续采集
HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adc_buf, BUF_SIZE);

// DMA 完成回调
void HAL_ADC_ConvHalfCpltCallback(ADC_HandleTypeDef* hadc) {
    // 前半缓冲区已填充
}
void HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef* hadc) {
    // 后半缓冲区已填充
}
```

> 串行外设接口

SPI（Serial Peripheral Interface）是一种高速同步串行通信协议，常用于连接 Flash、LCD、传感器等外设。

# I2C

> 集成电路间总线

I2C（Inter-Integrated Circuit）是一种两线制串行通信协议，适用于连接低速外设，如传感器、EEPROM 等。

## I2C 特性

- 仅需 SCL（时钟）和 SDA（数据）两根线
- 支持多主多从模式
- 7 位/10 位地址模式
- 标准模式 100 kHz / 快速模式 400 kHz
- 支持 DMA 传输
- 支持 SMBus 协议

## 通信流程

1. 主机发送 START 条件
2. 发送从机地址 + 读/写位
3. 从机应答 ACK
4. 数据传输
5. 主机发送 STOP 条件

## 常用设备

- AT24C02 EEPROM
- BMP280 气压传感器
- MPU6050 加速度计
- OLED 显示屏（SSD1306）

# RTOS

> 实时操作系统

RTOS（Real-Time Operating System）是专为实时应用设计的操作系统，为嵌入式系统提供任务调度、同步和通信机制。

## 核心概念

- **任务**：独立的执行单元，有优先级
- **调度器**：根据优先级决定运行哪个任务
- **信号量**：任务间同步机制
- **互斥量**：资源互斥访问
- **消息队列**：任务间数据传递
- **事件标志**：多事件同步

## FreeRTOS 在 STM32 上的使用

```c
// 创建任务
xTaskCreate(vTask1, "Task1", 128, NULL, 1, NULL);
xTaskCreate(vTask2, "Task2", 128, NULL, 2, NULL);

// 启动调度器
vTaskStartScheduler();

// 任务函数
void vTask1(void *pvParameters) {
    for (;;) {
        // 任务逻辑
        vTaskDelay(pdMS_TO_TICKS(100));
    }
}
```

# 电源管理

> STM32 电源与低功耗

STM32 提供多种低功耗模式，适用于电池供电和能量收集等应用场景。

## 低功耗模式

| 模式 | CPU | Flash | RAM | 唤醒方式 | 功耗 |
|------|-----|-------|-----|----------|------|
| 睡眠 | 停 | 运行 | 保持 | 任意中断 | ~mA |
| 停机 | 停 | 停 | 保持 | EXTI | ~μA |
| 待机 | 停 | 停 | 丢失 | WKUP/RTC | ~μA |
| 关断 | 停 | 停 | 丢失 | NRST | ~nA |

## 降低功耗的方法

1. 降低系统时钟频率
2. 关闭未使用的外设时钟
3. 使用低功耗模式
4. 优化 GPIO 配置（避免浮空）
5. 使用 [[DMA]] 减少 CPU 活动时间
6. 使用 RTC 定时唤醒

## 编程示例

```c
// 进入停机模式
HAL_PWR_EnterSTOPMode(PWR_LOWPOWERREGULATOR_ON, PWR_STOPENTRY_WFI);
// 唤醒后重新配置时钟
SystemClock_Config();
```

# 实时系统

> 实时系统概念与分析

实时系统要求在确定的时间内完成特定任务，是嵌入式系统的核心特性之一。

## 实时性分类

| 类型 | 说明 | 示例 |
|------|------|------|
| 硬实时 | 错过截止时间会导致灾难 | 安全气囊 |
| 软实时 | 错过截止时间降低质量 | 视频播放 |
| 固实时 | 错过截止时间结果无用 | 金融交易 |

## 实时性指标

- **响应时间**：从事件发生到开始处理
- **截止时间**：任务必须完成的时间
- **抖动**：响应时间的变化量
- **最坏情况执行时间（WCET）**

## STM32 实时性保障

- [[中断]] 快速响应（12 周期）
- [[ARM Cortex-M]] 嵌套中断
- [[RTOS]] 优先级调度
- [[DMA]] 减少延迟

# RTC

> 实时时钟

RTC（Real-Time Clock）是 STM32 内置的实时时钟外设，可在低功耗模式下持续运行，提供日历和闹钟功能。

## 主要特性

- 日历功能：年月日时分秒
- 闹钟功能：支持 A/B 两个闹钟
- 周期性唤醒定时器
- 后备寄存器（VBAT 供电保持）
- 支持时间戳和篡改检测

## 低功耗应用

- 在 [[电源管理]] 停机/待机模式下仍可运行
- 可配置唤醒周期，定时唤醒 MCU
- 闹钟中断可唤醒系统

## 编程示例

```c
// 设置 RTC 时间
RTC_TimeTypeDef sTime = {0};
sTime.Hours = 12;
sTime.Minutes = 30;
sTime.Seconds = 0;
HAL_RTC_SetTime(&hrtc, &sTime, RTC_FORMAT_BIN);

// 设置闹钟唤醒
HAL_RTC_SetAlarm_IT(&hrtc, &sAlarm, RTC_FORMAT_BIN);
```

# 时钟系统

> STM32 时钟树与配置

STM32 的时钟系统是整个芯片运行的基础，通过时钟树为各外设提供精确的时钟信号。

## 时钟源

| 时钟源 | 频率 | 说明 |
|--------|------|------|
| HSE | 4-26 MHz | 外部高速晶振 |
| HSI | 16 MHz | 内部高速 RC |
| LSE | 32.768 kHz | 外部低速晶振 |
| LSI | 32 kHz | 内部低速 RC |

## PLL 配置

PLL（锁相环）用于倍频，将输入时钟倍频到系统所需频率：
- STM32F4 最高 168 MHz
- STM32H7 最高 480 MHz
- STM32L4 最高 80 MHz

## 时钟分配

- SYSCLK：系统时钟
- HCLK：AHB 总线时钟
- PCLK1：APB1 总线时钟（低速）
- PCLK2：APB2 总线时钟（高速）

## 配置工具

通过 [[STM32CubeMX]] 可视化配置时钟树，自动计算各参数。
